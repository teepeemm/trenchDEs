There are two main differences by Trench compared to other differential equations texts, relating to the use of variation of parameters.
We explore these differences.

\setcounter{section}{2}
\subsection{Linear First Order Equations}

A linear first order equation can be written
\begin{equation}
y'+p(x)y=f(x).\label{first_order}
\end{equation}

Most texts solve this using the integrating factor $\mu(x)=\exp\{\int p(x)dx\}$, so that
\begin{align*}
\mu(x)y'+\mu(x)p(x)y&=\mu(x)f(x)\\
(\mu(x)y)'&=\mu(x)f(x)\\
\mu(x)y&=\int\mu(x)f(x)dx+C\\
y&=(\mu(x))^{-1}\int\mu(x)f(x)dx+C/\mu(x).
\end{align*}

Trench first observes that $y_1'+p(x)y_1=0$ can be separated to find a particular solution $y_1=c\exp\{-\int p(x)dx\}$.
Using variation of parameters, we write $y=uy_1$ so that $y'=u'y_1+uy_1'$ and \eqref{first_order} implies
\[
f(x)=y'+p(x)y=u'y_1+uy_1'+p(x)uy_1=u'y_1+u(y_1'+p(x)y_1)=u'y_1.
\]
Therefore, $u=\int f(x)/y_1dx+C$, and $y=y_1\int f(x)/y_1dx+Cy_1$ solves \eqref{first_order}.

Note that $y_1=c/\mu(x)$.

\stepcounter{section}
\subsection{Semilinear Numerical Methods}

Given a differential equation $y'=f(x,y)$, $y(x_0)=y_0$, numerical methods use the steps $x_{i+1}=x_i+h$, $y_i'=g(x_i,y_i,f)$, and $y_{i+1}=y_i+hy_i'$ for various formulations of $g$.
An equation is said to be \textit{semilinear} if we can write it as $y'+p(x)y=h(x,y)$.
Let $y_1=c\exp\{-\int p(x)dx\}$ be a solution of the complementary equation $y'+p(x)y=0$, and define $y=uy_1$.
Applying the formulation $g$ to $u$ leads to the step $u_i'=g(x_i,u_i,f/y_1)$.

To help explain, we reproduce Example 3.1.4(b): solving the initial value problem $y'-2xy=1$, $y(0)=3$, using the Euler semilinear method for $h=0.05$.
The complementary equation $y'-2xy=0$ has a solution $y_1=e^{x^2}$.
To involve variation of parameters, we write $y=uy_1$ as a solution of the initial value problem, so that
\begin{align*}
y'&=1+2xy=1+2xuy_1 \\
y'&=u'y_1+uy_1'=u'y_1+u2xy_1
\end{align*}
and $u'=1/y_1=e^{-x^2}$.
